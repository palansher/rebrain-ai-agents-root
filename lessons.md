# уроки по git tags

- Закоммитить локально

- Создать tag

`git tag lesson-02`

- Отправьте теги на GitHub

`git push origin main --tags`

На сайте GitHub в выпадающем списке веток (где обычно написано main) появится вкладка Tags, где можно будет легко переключаться между версиями кода для каждого урока.
